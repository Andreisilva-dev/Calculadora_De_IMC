# Calculadora de IMC

Esta é uma aplicação simples para calcular o **Índice de Massa Corporal (IMC)** com base na fórmula clássica:  

\[
IMC = \frac{peso (kg)}{altura^2 (m)}
\]

A calculadora classifica o IMC em diferentes faixas de acordo com as orientações da OMS (Organização Mundial da Saúde).

## Como Funciona

- O usuário insere o peso (em quilogramas) e a altura (em metros).
- O programa calcula o IMC utilizando a fórmula acima.
- O resultado é exibido com a classificação correspondente, por exemplo: **Abaixo do Peso**, **Peso Normal**, **Sobrepeso**, etc.

## Funcionalidades

- Cálculo automático do IMC.
- Exibição da faixa de IMC: **Abaixo do Peso**, **Peso Normal**, **Sobrepeso**, **Obesidade**.
- Interface simples e intuitiva.
- Validação de entradas para garantir dados corretos.
